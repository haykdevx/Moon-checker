## Named rules

| Rule | Kind | Meaning | Legitimate lookalikes | Limits |
|---|---|---|---|---|
| `files:known-cheat-hash` | DETECTION | The file's SHA-256 equals a sample a maintainer classified as a cheat. | None for the exact file; a hash identifies content, not who put it there. | Possession, not proof of use. Any rebuild of the cheat has a new hash. |
| `environment:test-signing` | CONFIGURATION | Windows accepts test-signed kernel drivers. | Driver developers and some hardware tools. | Lowers the assurance of the scan; never a verdict. |
| `environment:virtual-machine` | CONFIGURATION | The checker ran inside a virtual machine. | Players testing the checker; the gaming PC may be a different machine. | Lowers assurance: the inspected system may not be the one used to play. |
| `kernel:boot-integrity-weakened` | CONFIGURATION | Boot options weaken kernel integrity (e.g. integrity checks disabled). | Debugging setups, old tweak guides. | Lowers assurance; never a verdict. |
| `kernel:dse-off` | CONFIGURATION | Driver signature enforcement is off. | Driver development. | Lowers assurance; never a verdict. |
| `kernel:tainted` | CONTEXT | The Linux kernel reports taint flags. | NVIDIA's proprietary driver on almost every gaming PC. | Context only. |
| `kernel:hidden-process` | CONCEALMENT | A process the Linux kernel component lists is absent from /proc, re-checked after the diff. | PID namespaces (the checker running inside a container) and races the re-check did not catch. | Review required. A kernel-mode rootkit can hide from both views, so an empty diff proves nothing. |
| `kernel:driver-outside-windows` | INDICATOR | A Windows kernel module was loaded from outside the Windows folder (from the kernel component's module list). | Anti-cheats of other games, VPN, virtualisation and peripheral drivers under Program Files. | LOW severity: listed for the reviewer, never a reason to review on its own. |
| `kernel:module-hidden` | CONCEALMENT | A kernel module appears in one view and not another. | Modules loading or unloading during the scan. | Review required. |
| `steam:vac-ban` | CONTEXT | An account that logged in on this PC has a VAC ban on record. | Shared PCs, bought second-hand accounts. | History, not evidence of current cheating. |
| `steam:multiple-accounts` | CONTEXT | Several Steam accounts have logged in on this PC. | Family PCs, internet cafés. | Context only. |
