# Moon Checker + Moon Panel — инструкция

[English version](README.md)

Инструмент проверки ПК игроков CS2 для сервера MOON.

- **Moon Checker** — программа, которую игрок запускает на своём ПК (Windows 10/11, Linux).
  Она ищет следы читов и отправляет отчёт с уликами на панель.
- **Moon Panel** — сайт для администраторов: https://cs2-moon.com. Там создаются коды
  проверки, видно проверку в реальном времени, хранятся отчёты, решения, апелляции и статистика.

Проверка — это осмотр, а не приговор. «Улик в отчёте нет» не значит «ПК чист», а находка —
повод посмотреть самому, а не готовое решение. Что именно панель может и не может подтвердить,
написано на странице проверки в блоке «Об этом отчёте».

## Как пользоваться

### Администратор
1. Войдите на https://cs2-moon.com. Для всех обязательна двухфакторная защита (приложение
   Google Authenticator, Aegis, 2FAS и т. п.) — при первом входе панель покажет QR-код.
2. **Новая проверка** → введите ник игрока → панель покажет код вида `ABCD-EFGH` и готовое
   сообщение со ссылкой на скачивание. Отправьте его игроку.
3. Смотрите демонстрацию экрана игрока. Страница проверки обновляется сама, пока идёт сканирование.
4. Откройте результат:
   - итог (панель сама пересчитывает его по уликам);
   - найденное;
   - какие разделы проверки отработали;
   - блок «Об этом отчёте»: что панель проверила сама, а что только сообщил ПК игрока.
5. **Сверьте код подтверждения:** код в окне чекера у игрока должен совпасть с кодом на
   странице проверки.
6. Запишите решение: чисто / бан / нужен второй взгляд / перепроверить. Игрок увидит его на
   своей странице и сможет подать апелляцию — её разбирает другой администратор.

### Игрок
1. Скачайте `MoonCheck-<версия>-win64.zip` со страницы https://cs2-moon.com/download/ и распакуйте
   (папка `runtime` должна лежать рядом с `MoonCheck.exe`).
2. Правый клик по `MoonCheck.exe` → «Запуск от имени администратора». Если Windows SmartScreen
   предупредит — «Подробнее» → «Выполнить в любом случае».
3. Введите код от администратора, проверьте, что показан ник вашего администратора, нажмите
   «Начать проверку».
4. Не закрывайте окно, пока не появится «Результаты доставлены».

Удаление: удалите папку чекера. На ПК остаются только журналы в `%LOCALAPPDATA%\MoonCheck` —
они удаляются сами через 14 дней или сразу командой `MoonCheck.exe --forget`. Ничего не
устанавливается: ни служб, ни драйверов, ни автозапуска.

## Команда и настройки

- **Команда** — пригласить администратора (ссылка-приглашение), изменить роль, сбросить пароль
  или 2FA. Выдать можно только роль ниже своей и только с правами, которые есть у вас самих.
- **Роли:** Владелец, Старший админ, Админ, Стажёр, Наблюдатель, плюс свои роли.
- **Настройки:**
  - срок действия кода;
  - сколько хранить проверки;
  - обязательность 2FA;
  - минимальная версия чекера;
  - список официальных сборок;
  - «Принимать чекеры старше 1.3» (только на время перехода).
- **Журнал** — кто что делал на панели. Личные данные игрока удаляются из журнала вместе с
  его проверкой.
- **Статистика**, **история игрока**, **апелляции и запросы на удаление данных** — в меню панели.

## Передача проекта: что где лежит

| Что | Где |
|---|---|
| Исходный код | GitHub, ветка `main` |
| Панель на сервере | VPS `185.182.9.52`, папка `/opt/moon-panel`, Docker Compose проект `moon-panel` |
| Резервные копии базы | `/root/moon-panel-backups/` на том же VPS |
| Домен | `cs2-moon.com` (Namecheap): записи A `@` и `www` → `185.182.9.52`; сертификат Let's Encrypt продлевается сам |
| Сборки чекера для игроков | страница https://cs2-moon.com/download/ (текущая версия — 1.4.0) |

На VPS работают и другие сервисы. Трогайте только `/opt/moon-panel` и контейнеры `moon-panel-*`.
Перед `systemctl reload nginx` всегда запускайте `nginx -t`.

**Первые шаги нового владельца:**
1. Войдите, смените пароль на длинный и включите 2FA; сохраните резервные коды в надёжном месте.
2. Смените токен GitHub и пароли, которые передавались в чате или мессенджере.
3. В «Команде» проверьте, что у каждого администратора своя учётная запись и подходящая роль.
4. Удалите или оставьте проверки, сделанные при тестировании выпусков («Release check …»).
5. Убедитесь, что игроки скачивают 1.4.0: чекеры старше 1.3 панель не принимает.

**Если потеряли доступ владельца** (на сервере):

```bash
cd /opt/moon-panel
docker compose exec web python manage.py bootstrap_owner <логин> --reset
```

Команда выдаст одноразовый пароль и сбросит 2FA этой учётной записи; при входе панель
попросит задать новый пароль и снова включить 2FA.

## Технологии

| Часть | Технологии |
|---|---|
| Чекер | Java 21, Swing + FlatLaf (окно), JNA (вызовы Windows / Linux), Jackson (JSON), SQLite JDBC (история браузеров), Maven |
| Пакет для Windows | `.exe` (launch4j) + встроенная среда Eclipse Temurin 21 (версия закреплена, контрольная сумма проверяется), воспроизводимая сборка |
| Драйверы ядра (необязательно) | C: драйвер Windows и модуль Linux — игрокам не выдаются |
| Панель | Python 3.13, Django 5.2, gunicorn, whitenoise, пароли argon2, 2FA (TOTP) |
| База данных | PostgreSQL 17 (сервер), SQLite (разработка и тесты) |
| Сервер | Docker Compose (db, web, worker) за nginx, сертификаты Let's Encrypt |
| Языки | русский по умолчанию, английский |

Папки репозитория:
- `src/` — чекер;
- `web/` — панель;
- `kernel/` — драйверы;
- `scripts/` — сборка, подпись правил, тест для Windows;
- `docs/` — документация.

## Сборка, тесты, выкладка

```bash
# тесты чекера (через Docker, Maven ставить не нужно)
docker run --rm -u $(id -u):$(id -g) -v "$PWD":/src -v "$HOME/.m2":/var/maven/.m2 -w /src \
  maven:3.9-eclipse-temurin-21 mvn -Duser.home=/var/maven -Dmaven.repo.local=/var/maven/.m2/repository -B test

# пакет для Windows -> build/MoonCheck-<версия>-win64.zip
bash scripts/build-exe.sh

# панель локально
cd web && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
export DJANGO_DEBUG=1
.venv/bin/python manage.py migrate
.venv/bin/python manage.py runserver
DJANGO_DEBUG=1 .venv/bin/python manage.py test       # тесты панели

# выкладка на сервер (cs2-moon.com, www и старый адрес sslip)
bash web/deploy/deploy.sh
```

**Перед выкладкой с изменениями базы** сделайте резервную копию на сервере:

```bash
cd /opt/moon-panel
docker compose exec -T db pg_dump -U moon moon | gzip > /root/moon-panel-backups/<дата>.sql.gz
```

`deploy.sh` сам публикует новые сборки чекера из `build/panel-downloads/` и отмечает их как
официальные.

## Важные ограничения

- Точность обнаружения настоящих читов не измерена (нет размеченных образцов). Ложные
  срабатывания измерены: 0 на 61 423 системных файлах Windows и Linux.
- `MoonCheck.exe` пока не подписан сертификатом — Windows показывает предупреждение SmartScreen.
- Драйверы ядра не подписаны для продакшна и игрокам не выдаются.
- Непрерывной защиты во время игры нет: это разовая проверка под наблюдением администратора.
